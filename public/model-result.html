1. 데이터 분할 전략

분할 비율: Train 64% / Validation 16% / Test 20% (모두 stratified)

왜 이렇게 나눴는가?
  • Test (448, 67 양성): 학습/검증 어디에도 노출되지 않는 최종 홀드아웃. 모델 성능의 unbiased 추정용.
  • Validation (358, 53 양성): 임계값(threshold) 튜닝 + LightGBM 조기종료에 사용. test 정보 누수 방지.
  • Train (1,430, 214 양성): 두 모델 학습용. 양성 샘플 200+를 확보해 안정적 학습이 가능.
  • Stratified split으로 세 셋 모두 양성 비율을 14.8~15.0%로 일치시켜 평가 신뢰도 확보.
  • 대안인 5-fold CV는 모델 선정에 더 적합하나, 본 단계는 모델별 진단·시각화가 목적이라 fixed split이 더 명료.

4. 시각화 결과

4-1. ROC Curves

해석. 두 모델의 ROC 곡선이 거의 겹친다 (AUC 차이 ≤ 0.01). 랜덤 기준선보다 한참 위에 있고, validation/test 간 격차가 작아 과적합 우려가 거의 없음을 시사한다. LR의 우상단 모서리가 더 가깝게 도달 — Recall 영역에서 약간 우세하지만 통계적으로 유의한 차이라 보긴 어렵다.

4-2. Precision-Recall Curves

해석. 양성 비율 14.9% 베이스라인(점선) 대비 두 곡선 모두 4배 이상 위에 위치. 왼쪽(낮은 recall)에서는 LightGBM이 우세(높은 정밀도 유지), 오른쪽(높은 recall)에서는 LogReg가 더 견고. 즉, "소수만 정확히 타겟팅"이면 LGBM, "많이 잡아내야 하면" LR이 유리한 trade-off가 명확하다.

4-3. Confusion Matrices (Test, 최적 threshold)

해석.
  • LR (th=0.66): TP=39, FP=34, FN=28 — 67명 양성 중 39명 검출 (Recall 58%), 73명 발송 중 39명 적중(Precision 53%).
  • LGBM (th=0.59): TP=34, FP=20, FN=33 — 더 보수적 — 54명 발송 중 34명 적중(Precision 63%).
  • LR은 "많이 발송, 더 많이 적중", LGBM은 "적게 발송, 더 정확히 적중"의 페르소나를 보인다.

4-6. 예측 확률 분포 by 실제 클래스 (Test)

해석.
  • 이상적인 분류기는 두 분포가 좌우로 완전 분리된다. 두 모델 모두 실제 양성(컬러) 분포가 오른쪽에 위치해 변별력이 있음을 확인.
  • LightGBM의 양성 분포는 0.4~0.9 구간에 폭넓게 퍼짐 (확률 보정 양호).
  • LogReg의 양성 분포는 0.5~0.95에 집중 → threshold 변경에 더 민감.
  • 중첩 영역(0.3~0.7)이 모델이 헷갈리는 구간 — 추가 피처 또는 앙상블로 보강 가능.

4-7. Threshold-F1 + 누적 게인(Gain) 차트

해석 — 비즈니스 의사결정 지원.
  • 왼쪽(F1 vs Threshold): 두 모델 모두 0.5~0.7 구간에서 F1이 최대, 그 외 구간은 급격히 감소 → 운영 시 임계값을 이 범위에서 정해야 안정적.
  • 오른쪽(누적 게인): 예측 확률 상위로 정렬 후 N% 발송 시 잡히는 실제 수락자 비율.
  • Top 20% 발송 시: LR이 62.7%, LGBM이 70.1%의 양성을 잡는다 → LGBM이 더 효율적.
  • Top 30% 발송 시: LR 79.1%, LGBM 86.6%.
  • Top 50% 발송 시: 두 모델 모두 94~96% 양성 캡쳐 → 발송량을 절반으로 줄여도 거의 모든 잠재 수락자를 놓치지 않는다.
비즈니스 시사점: "예산이 빠듯해 30%만 발송"한다면 LightGBM으로 정렬한 상위 30%를 보내면 잠재 수락자의 87%를 잡을 수 있다 (전체 발송 대비 비용 70% 절감, 매출 손실은 13%). ROI 관점에서 강력한 전략.
