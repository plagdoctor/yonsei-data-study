🎯 분석 목표
고객의 인구통계·구매·캠페인 이력 정보를 활용해 마지막 캠페인의 수락 여부(Response = 1)를 사전에 예측하는 이진 분류 모델을 구축한다.

예정 STAGE 4. 클래스 불균형 처리 Week 3

현재 수락률 14.9% → 단순 정확도(accuracy)로는 모델 성능을 가늠할 수 없음.

전략세부 내용비고
4-1. 평가지표 변경Accuracy 대신 F1, Recall, ROC-AUC, PR-AUC 중심가장 우선
4-2. 가중치 조정class_weight='balanced' 또는 scale_pos_weight가장 간단·강력
4-3. 오버샘플링SMOTE / SMOTENC / Borderline-SMOTEimblearn
4-4. 언더샘플링RandomUnderSampler / TomekLinks데이터 손실 주의
4-5. 임계값(Threshold) 튜닝기본 0.5 → PR 곡선 기반 최적 threshold 탐색비즈니스 비용반영 가능

⚠️ 주의: 오버샘플링은 반드시 train fold 내부에서만 적용 (Pipeline 사용)

예정 STAGE 5. 모델 학습 — Baseline → 후보 모델군 Week 4-5

모델 후보특징라이브러리
5-1. Logistic RegressionBaseline. 해석 쉬움, 계수로 영향력 파악sklearn
5-2. Decision Tree시각화·해석 용이, 과적합 위험sklearn
5-3. Random Forest안정적 성능, feature importance 제공sklearn
5-4. Gradient Boosting일반적으로 표 데이터에서 최고 성능sklearn / XGBoost / LightGBM / CatBoost
5-5. SVM스케일링된 데이터에 적용, 커널 선택sklearn
5-6. KNN거리기반, 단순 비교용sklearn
5-7. Stacking / Voting여러 모델 앙상블sklearn

5단계 표준 절차

  • 각 모델을 5-Fold Stratified Cross-Validation으로 학습
  • 지표는 ROC-AUC + F1(Response=1 기준)를 메인으로 비교
  • 학습 시간·예측 시간도 함께 기록 (운영 비용 고려)
  • 상위 2~3개 모델을 STAGE 6 튜닝 대상으로 선정

예정 STAGE 6. 하이퍼파라미터 튜닝 Week 6

하위 업무세부 내용
6-1. 탐색 전략 선택GridSearchCV(전수) / RandomizedSearchCV(빠름) / Optuna(베이지안, 권장)

· LogReg: C, penalty (L1/L2/elasticnet), class_weight
6-4. 조기종료(early stopping)Boosting 계열은 valid set으로 early_stopping_rounds 설정
6-5. 임계값(threshold) 최적화예측 확률 + Precision/Recall trade-off 곡선으로 비즈니스 목적 맞춤

예정 STAGE 7. 최종 평가 & 모델 해석 Week 7

7-1. 성능 평가 (Test set, 한 번만)

지표의미이 프로젝트에서 중요도
Accuracy전체 정확도참고용 (불균형이라 신뢰 낮음)
Precision예측한 수락자 중 실제 수락 비율★★★ 캠페인 비용 절감 관점
Recall실제 수락자 중 잡아낸 비율★★★ 매출 기회 손실 관점
F1-scorePrecision·Recall 조화평균★★★ 메인 지표
ROC-AUC임계값 무관한 분류 능력★★★ 모델 비교
PR-AUC불균형 데이터에서 더 신뢰★★★ 보조 지표
Confusion MatrixTP/FP/FN/TN 분해★★ 비즈니스 비용계산
Lift Chart / Gain Chart상위 N% 타겟팅 시 잡히는 수락자 비율★★ 마케팅 의사결정

7-2. 모델 해석 (Explainability)

  • Feature Importance: 트리 계열의 기본 importance + Permutation Importance
  • SHAP Values: 개별 예측에 대한 변수 기여도 (글로벌 + 로컬)
  • Partial Dependence Plot: 특정 변수가 예측에 미치는 비선형 효과
  • 로지스틱 회귀 계수: odds ratio 해석 → 비즈니스 보고용

7-3. 학습/검증 곡선 점검

  • Learning curve — 데이터 추가 시 성능 향상 여지 확인
  • Train vs Test 성능 차이 — 과적합 여부 점검

하위 업무세부 내용
